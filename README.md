# Forge Studio

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/YOUR-GITHUB-NAME/forge-studio)

Tap the button, sign in to Render with GitHub, set `FORGE_PASSWORD`, and tap Apply.

Edit this file on GitHub and replace `YOUR-GITHUB-NAME` in the link with your GitHub username.
